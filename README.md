## 🚀 GitHub Pages 3분 무료 배포 가이드

1. **GitHub 회원가입 및 저장소(Repository) 생성**:
   * GitHub에서 **Create a new repository** 클릭
   * Repository Name: `portfolio` (또는 원하시는 이름)
   * Public 선택 후 **Create repository** 버튼 클릭
2. **파일 드래그 & 드롭 업로드**:
   * 생성된 저장소 화면에서 **`uploading an existing file`** 클릭
   * 내 컴퓨터의 **`index.html`**, **`README.md`**, **`assets` 폴더** 전체를 마우스로 끌어다 놓기!
   * 하단 초록색 **`Commit changes`** 클릭!
3. **웹사이트 무료 주소 생성**:
   * 저장소 상단 **`Settings`** -> 좌측 메뉴 **`Pages`** 클릭
   * Build and deployment의 Source를 **`Deploy from a branch`** 선택
   * Branch를 **`main`** / **`/ (root)`** 로 변경 후 **`Save`** 클릭!
   * 1~2분 뒤 나만의 평생 무료 공식 웹사이트 링크(`https://내아이디.github.io/portfolio`)가 생성됩니다!
